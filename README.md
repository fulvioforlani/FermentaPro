# FermentaPro
Programma in python semplice con ricette e calcolo per la fermentazione.

- Schede: Nuova ricetta, Ricettario, Database, **Guida**
- **GUIDA.md**: regole del sale (a secco = % sul peso delle verdure, salamoia = % sul peso dell'acqua), tara, sicurezza e ricetta di riferimento (rape, carote, sedano rapa)
- Avvio: `python FermentaPro.py`
